# DAYU MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the public, bilingual DAYU web application that produces an evidence-backed rules report for any public GitHub repository and optionally enriches it with the current user's GitHub Copilot entitlement.

**Architecture:** Use a pnpm TypeScript monorepo with a React web client, a long-running Fastify API, and focused packages for GitHub collection, evidence contracts, repository classification, deterministic scoring, Copilot analysis, bilingual copy, and share cards. Rules-only scans remain fully usable without OAuth; Copilot sessions are short-lived, tool-free, and isolated behind a server-side encrypted token vault.

**Tech Stack:** Node.js 24 LTS, pnpm 10, TypeScript, React, React Router, Fastify, Zod, Vitest, Testing Library, Playwright, Redis-compatible KV, Octokit, official GitHub Copilot SDK, Canvas API, ESLint, Prettier.

## Global Constraints

- Analyze public GitHub repositories only.
- The five dimension weights are Popularity 25%, Substance 25%, Maintenance 20%, Community 15%, and Claims 15%.
- The enhanced score is 70% deterministic rules and 30% optional user Copilot judgment.
- A rules-only report must work without login or Copilot.
- `watchers_count` means stars; real Watch uses `subscribers_count`.
- Missing or restricted data lowers coverage and confidence, never risk.
- If available total weight is below 60%, show “Insufficient evidence” instead of a precise total score.
- Every scored finding cites an existing Evidence ID pinned to a default-branch commit SHA where applicable.
- Repository content is untrusted data. Never clone, build, install, execute, or grant it tools.
- Copilot uses `mode: "empty"`, one isolated session per analysis, no tools, no credential fallback, and strict JSON output.
- OAuth tokens never reach React, browser storage, URLs, logs, reports, or share cards.
- No private repositories, rankings, maintainer-follower authenticity score, or permanent public AI reports in v1.
- Chinese and English use independent message templates while sharing identical facts, scores, and Evidence IDs.
- Product copy reports risk and mismatch, never proof of bought stars, fraud, or intent.
- Source code and project documentation use Apache-2.0.

```ts
const SEGMENT = /^[A-Za-z0-9_.-]+$/;

export function parseRepositoryInput(raw: string): { owner: string; repo: string } {
  const trimmed = raw.trim();
  const path = trimmed.includes("://") ? new URL(trimmed).pathname : trimmed;
  if (trimmed.includes("://") && new URL(trimmed).hostname !== "github.com") throw new Error("unsupported_host");
  const [owner, rawRepo, extra] = path.replace(/^\/+|\/+$/g, "").split("/");
  const repo = rawRepo?.replace(/\.git$/, "");
  if (!owner || !repo || extra || !SEGMENT.test(owner) || !SEGMENT.test(repo)) throw new Error("invalid_repository");
  return { owner, repo };
}
```

- [ ] **Step 5: Collect and normalize a pinned evidence envelope**

```ts
export interface CollectedRepository {
  repository: { id: number; fullName: string; defaultBranch: string; defaultSha: string; stars: number; subscribers: number };
  evidence: Evidence[];
  coverage: { attempted: number; complete: number; restricted: number; truncated: number };
  rateLimit: { remaining: number | null; resetAt: string | null };
}

export async function collectPublicRepository(ref: RepositoryRef, transport: GitHubTransport): Promise<CollectedRepository> {
  const root = `/repos/${encodeURIComponent(ref.owner)}/${encodeURIComponent(ref.repo)}` as const;
  const metadataResponse = await transport.get<GitHubRepository>(root);
  const repository = normalizeRepository(metadataResponse.data);
  if (repository.private) throw new Error("private_or_unavailable");
  const branch = await transport.get<GitHubBranch>(`${root}/branches/${encodeURIComponent(repository.defaultBranch)}`);
  const defaultSha = branch.data.commit.sha;
  const collected = await Promise.allSettled([
    transport.get(`${root}/git/trees/${defaultSha}?recursive=1`),
    transport.get(`${root}/languages`),
    transport.get(`${root}/community/profile`),
    transport.get(`${root}/issues?state=all&per_page=100&page=1`),
    transport.get(`${root}/pulls?state=all&per_page=100&page=1`),
    transport.get(`${root}/releases?per_page=100&page=1`),
    transport.get(`${root}/contributors?per_page=100&page=1`),
  ]);
  const normalized = settledToEvidence({ repository, defaultSha, collected, limits: PUBLIC_SCAN_LIMITS });
  return {
    repository: { id: repository.id, fullName: repository.fullName, defaultBranch: repository.defaultBranch, defaultSha, stars: repository.stars, subscribers: repository.subscribers },
    evidence: normalized.evidence.map((item) => evidenceSchema.parse(item)),
    coverage: normalized.coverage,
    rateLimit: readRateLimit(metadataResponse.headers),
  };
}
```

Implement the described calls directly. When GitHub returns 202, 403, a truncated tree, or an incomplete page budget, add a partial or restricted Evidence record instead of a risk signal.

```ts
const RULE_WEIGHTS = { popularity: 0.25, substance: 0.15, maintenance: 0.15, community: 0.10, claims: 0.05 } as const;
const AI_WEIGHTS = { substance: 0.10, maintenance: 0.05, community: 0.05, claims: 0.10 } as const;

export interface RulesReport extends ReportSnapshot {

}

export interface AiFinding {
  rubricId: string;
  dimension: "substance" | "maintenance" | "community" | "claims";
  verdict: "supported" | "mixed" | "contradicted" | "unverifiable" | "not_applicable";
  risk: 0 | 50 | 100 | null;

export interface EnhancedScoreInput {

export interface EnhancedReport extends ReportSnapshot {

export function weightedAvailableScore(parts: readonly ScorePart[]): number | null {
  const available = parts.filter((part) => part.status === "available");
  const weight = available.reduce((sum, part) => sum + part.weight, 0);
  if (weight < 0.60) return null;
  return Math.round(available.reduce((sum, part) => sum + part.risk * part.weight, 0) / weight);
}
```

Rule-only display normalizes available rule weight and uses the label `rules_only_signal`. Enhanced scoring uses all available rule and AI parts. Missing, restricted, truncated, and not-applicable parts are excluded and reduce confidence.

## Definition of Done

- A user can scan a public repository without login and receive an evidence-backed bilingual rules report.
- The report uses the approved five weights, withholds false precision, and links every finding to valid evidence.
- A consenting authenticated user can run one isolated analysis using their own Copilot entitlement.
- Copilot failure, quota exhaustion, policy denial, invalid output, or timeout preserves the rules report.
- Tokens remain server-side in a short-lived encrypted vault and are deleted on expiry, logout, or disconnect.
- English and Chinese reports share values and evidence while using natural independent copy.
- Share output is a local PNG or a current-data rescan URL, never a permanent hosted AI report.
- CI passes unit, contract, E2E, security, accessibility, isolation, and calibration gates.
- Public documentation accurately explains limitations, privacy, scoring, self-hosting, and Apache-2.0 licensing.
